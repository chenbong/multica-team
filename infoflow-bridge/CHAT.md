# 如流聊天与任务

普通消息默认发送到绑定智能体的 Multica 聊天会话，连续对话保留上下文。
会话按机器人、绑定账号、工作区、私聊/群聊、发送人隔离，切换智能体会创建新会话。
群里继续要求 @ 机器人；访问控制沿用机器人允许名单。

## 可选：绑定任务

启用 `INFOFLOW_ISSUE_RELAY_ENABLED=true` 后，私聊和群聊都支持 `/bind <任务编号>`、
`/binding [任务编号]`、`/unbind [任务编号]`；`/issue <内容>` 改为新建并绑定。
一个任务最多绑定一个群（等待入群确认也占用名额），一个群可以绑定多个任务。
`/bind` 添加关联，不替换群里的其他任务；解绑只处理选定任务。
私聊绑定仍按机器人和用户区分，不占用群绑定名额。真正未绑定时仍走普通聊天。

群消息依次按同群引用消息、显式任务编号、被 @ 智能体的唯一关联任务选择目标。
例如 A+B 负责 INFE-1，A+D 负责 INFE-2：`@B 继续` 进入 INFE-1，`@D 继续` 进入
INFE-2；`@A 继续` 有歧义，只询问，不评论、不执行。可回复对应任务的消息，或发
`@A INFE-2 继续` 明确目标。已知的跨群、跨工作区或私聊引用不能偷偷改投其他任务。
歧义提示的处理结果会持久保存，旧消息重投不会因为关联减少而自动变成可执行请求。

已绑定时，消息以实际发送人的平台身份发布到任务评论，而不是借用机器人绑定者的权限：

- 无工作区权限：不新增评论、不执行；提示向工作区 owner 申请权限。
- 有评论权限、无智能体调用权限：只新增评论；提示向智能体 owner 申请权限。
- 两者都有：新增评论，并遵循平台已有的智能体触发规则。

智能体回复按原始来源回到私聊或群，默认不强制 @ 用户；绑定模式的回复底部附
`完整任务对话：<任务链接>`。群回复对所有群成员可见，不额外检查全体成员的工作区权限。
如流中的每条文字回复（长消息的每个分片也一样）开头显示 `[聊天模式]` 或
`[任务模式] INFE-1:任务名称`。名称来自服务端授权元数据，只用于如流展示；缺失时仍显示编号，长名称会截断。未选定任务的歧义提示不编造任务编号、名称或单个任务链接。
前缀只在发送到如流时添加，不写入任务评论、聊天正文或智能体提示词。绑定成功显示任务模式，
私聊解绑恢复聊天模式；群里仍有任务关联时继续显示任务模式，解绑回执保留原任务链接。
延迟到达的智能体回复按其实际来源标注，
不会因当前绑定改变而把旧聊天回复标成任务回复。权限提示沿用当前绑定模式。
解绑不删除任务、不取消正在执行的工作。绑定期间的 `/new`、`/agent` 等聊天命令只显示
当前绑定或要求指定任务，不绕过任务权限进入绑定账号的聊天路径。

功能默认关闭；需先部署服务端专用身份接口和数据库迁移，再配置受限服务凭据。
完整权限、可靠性、测试和回退说明见 [任务绑定说明](../INFOFLOW-ISSUE-BINDING.md)。

## 原有聊天模式

- `/issue <内容>`：创建 issue，并将结果回复到当前会话。
- `帮我创建一个任务：<内容>`、`新建 issue：<内容>`：同上。
- `/new`：开始新对话，旧对话仍保留在网页版；不取消正在执行的请求。
- `/status`：查询当前聊天；没有聊天时查询本会话最近的 issue。
- `/status CBH-15`：查询指定 issue 的执行状态。群里仅返回发送者在该会话最近创建的任务。
- `/help`：查看用法。

模糊请求（例如“帮我优化性能”）、否定句、引用中的建单描述均按聊天处理。
自然语言建单采用明确的开头规则，不对模糊句子作模型猜测。
普通聊天直接传递用户消息，不附加固定的聊天模式提示词。建单分流由 Bridge 处理。
接收入口另外附上仅供显示的发送人、会话类型、群 ID 和已识别的提及对象，不作为权限依据。
普通聊天可以执行工具，因此仍可能消耗运行时资源；Bridge 分流不是对智能体工具的服务器权限限制。

聊天图片通过附件 API 上传，引用消息保留现有解析结果。
会话及待回传的执行 ID 保存到 `state.json.chat-<scope>.json`（权限 0600），
Bridge 重启后继续等待已提交请求的回复。每轮按 task_id 匹配，不回传其他轮次的答案。
超时后可用 `/status` 或网页版查看。网络中断时发送结果可能不确定，不自动重发用户输入。
账号身份沿用机器人绑定的 Multica profile，聊天会出现在该账号的网页版中。

部署：加载 `deploy/env.sh` 后重启 Bridge，以继承 IM API 地址等部署配置。
聊天状态文件应与 `config.local.json`、`state.json` 一并纳入实例备份；不要提交 Git。
