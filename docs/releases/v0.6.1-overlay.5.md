# Team Mesh v0.6.1-overlay.5

## 如流任务回复

- 任务回复抬头新增任务名称，例如 `[任务模式] INFE-12:示例任务`，群聊和私聊都更容易辨认。
- 任务改名后，新回复使用新名称；长名称安全截断，特殊字符按普通文字展示。
- 保留 Markdown 正文、正常链接和独立的真实 @ 提醒；继续支持网页评论及智能体回复同步。
- 兼容已有投递进度，升级或重试不会因为新增标题重复发送已接受的正文。

## 工作区与任务面板

- 支持添加共享页面链接，在右侧面板打开、调整宽度、刷新，或转到新标签页。
- 受网站限制、加载超时或反复刷新时显示提示，提供新标签页入口。
- 支持智能体在当前任务中新增任务面板链接，工作区面板仍由用户手动维护。
- 智能体自动新增需要本版 CLI；仅更新服务端不会替现有客户端完成升级。

## 显示优化

- 登录页标题支持独立配置，保留原有说明与支持链接。
- Markdown 支持 `\(...\)` 行内公式与 `\[...\]` 块级公式，兼容已有公式写法，代码示例保持原样。

## Linux 客户端自动升级

- 支持定期检查本仓库的正式 Release，空闲时校验并升级；忙碌或正在领取任务时跳过。
- 新版通过启动健康确认后才开始领取任务；启动失败时恢复旧版，并保留配置、登录凭据和任务文件。
- 支持正式 `x.y.z-overlay.N` 版本比较，开发构建不参与自动升级。
- 自部署默认保持显式启用，可在客户端启动环境中设置：

  ```ini
  MULTICA_DAEMON_AUTO_UPDATE=true
  MULTICA_DAEMON_AUTO_UPDATE_INTERVAL=1h
  ```

- 旧客户端需要先做一次受控引导升级。仅发布本版不等于自动升级所有现有客户端。
- 第一版面向普通 Linux CLI daemon；PID 1、已识别的托管启动、共享安装等场景会拒绝自动安装。
- 回退覆盖启动阶段失败，不回退开始执行任务后的业务错误，也不是宿主机断电恢复机制。

各平台安装包随 Release 提供，下载后可用 `checksums.txt` 校验。自动升级功能仅在受支持的 Linux 启动方式中启用。
